# Breast Tumor AI — 3-Stage DCE-MRI Pipeline

A complete deep learning pipeline for breast MRI analysis using
3-channel DCE-MRI (Dynamic Contrast-Enhanced MRI) volumes.

---

## Pipeline Overview

```
Input: 3-channel DCE-MRI (P1 → pre-contrast, P2 → peak enhancement, P3 → delayed)
         ↓
Stage 1: Tumor Detection (3D ResNet18 + CBAM)
         ↓ if positive
Segmentation: Tumor mask + metrics (MONAI UNet3D + DynUNet ensemble)
         ↓
Stage 3: Benign vs Malignant (3D EfficientNet-B0)
```

Each DCE phase captures a different moment of contrast agent uptake:
- **P1 (pre-contrast):** baseline tissue signal before injection
- **P2 (peak enhancement):** maximum tumour enhancement ~90 s post-injection
- **P3 (delayed):** washout phase ~3–5 min post-injection, used to characterise kinetic type

## Results

| Stage | Model | Params | Key Metric | Value |
|-------|-------|--------|-----------|-------|
| Stage 1 — Detection | 3D ResNet18 + CBAM | 33.4M | Test AUC | 0.8765 |
| Segmentation | MONAI UNet3D + DynUNet ensemble | — | Mean Dice | 0.80 |
| Segmentation | MONAI UNet3D + DynUNet ensemble | — | Highest Dice | 0.9582 |
| Stage 3 — Classification | 3D EfficientNet-B0 | 4.7M | Test AUC | 0.9200 |

**How to read these numbers:**
- **AUC (Area Under the ROC Curve):** ranges 0–1; 1.0 = perfect classifier, 0.5 = random guess. An AUC of **0.8765** for Stage 1 means the model correctly ranks a tumour patient above a normal patient ~88% of the time. An AUC of **0.9200** for Stage 3 (benign vs malignant) is strong clinical-grade performance.
- **Dice coefficient:** measures overlap between the predicted tumour mask and the ground-truth annotation; ranges 0–1 where 1.0 = perfect overlap. A **mean Dice of 0.80** across the test set is solid for 3D breast MRI segmentation. The **highest single-patient Dice of 0.9582** (patient 67, full sliding-window inference) demonstrates the ensemble's capability on well-defined tumours.

> **Note on segmentation inference:** The pipeline uses sliding-window inference on the full volume (96³ patches, 0.5 overlap, Gaussian weighting) with a MONAI 0.35 / DynUNet 0.65 ensemble blend. This exactly replicates the training evaluation protocol and avoids spatial cropping artefacts that would otherwise reduce Dice by ~0.05.

## Tumour Feature Extraction

For each segmented tumour the pipeline computes the following features used in downstream analysis and the per-patient tables:

**Geometry:** voxel count · volume (mm³) · surface area (mm²) · centroid · bounding box dims (mm) · max diameter (mm) · sphericity · compactness · elongation · connected component count · T-stage

**DCE Kinetics:** mean signal per phase (P1/P2/P3) · enhancement ratio `(P2−P1)/|P1|` · washout rate `(P2−P3)/|P2|` · kinetic type (Persistent I / Plateau II / Washout III)

**Texture (P2 channel inside mask):** mean intensity · std intensity · min/max intensity · contrast (max−min) · homogeneity `1 − std/(max−min)`

Voxel spacing is assumed to be **1.5 mm isotropic** (`VOXEL_MM3 = 3.375 mm³`, `VOXEL_SURF = 2.25 mm²`).
